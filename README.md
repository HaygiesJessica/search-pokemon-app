# Pokémon Search App

A React app for searching and displaying Pokémon data using the PokéAPI.

## Features

- Search Pokémon by name
- Display Pokémon image and ID
- Show height and weight
- Display Pokémon types
- Display abilities
- Display base stats
- Play Pokémon cries
- Responsive design for desktop, tablet, and mobile
- Handles loading and invalid searches

## Technologies

- React
- Vite
- JavaScript
- CSS
- PokéAPI

## API

This project uses the PokéAPI to retrieve Pokémon data.

https://pokeapi.co/
